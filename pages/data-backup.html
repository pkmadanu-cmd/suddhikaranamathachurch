Data Backup

Export all parish records to a file or import records from a previous backup.

Export All Records

Download a JSON backup containing Family Cards, Baptism, Burial, First Holy Communion, Confirmation, Marriage, Mass Intentions, Church Expenses, and Family Card Subscriptions.

Recommended: make a backup regularly and store a copy somewhere safe, such as a USB drive or secure computer folder.

Import / Restore Backup

Select a backup JSON file previously exported by ChurchRecords. Records with matching document IDs will be replaced by the backup versions; other records will be added. Records not present in the backup will not be deleted.

Please be careful: importing can replace current records that have the same IDs. Make a fresh backup before restoring.
